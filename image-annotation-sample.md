# Image Annotation Practice Sample

## Overview

This is a practice sample demonstrating my approach to analyzing images for AI annotation.

The focus is on identifying visible subjects, objects, actions, environments, and spatial relationships using clear and objective descriptions.

## Annotation Example

| Element              | Annotation                                                             |
| -------------------- | ---------------------------------------------------------------------- |
| Primary subject      | A person standing inside a room                                        |
| Objects              | Table, chair, bag, and other visible household items                   |
| Action               | The person is standing and interacting with an object                  |
| Environment          | Indoor residential setting                                             |
| Spatial relationship | The table is positioned in front of the person                         |
| Visual details       | The room contains multiple visible objects arranged around the subject |
| Lighting             | Indoor lighting is visible in the scene                                |

## Observation Approach

When analyzing an image, I focus on information that can be directly observed rather than making assumptions.

I consider:

* Who or what is visible
* What the subjects are doing
* Where the scene takes place
* Objects present in the image
* Relationships between subjects and objects
* Position and spatial relationships
* Relevant visual details
* Lighting and overall visual conditions

## Quality Considerations

For consistent annotation, I aim to:

* Use clear and objective descriptions
* Avoid unsupported assumptions
* Follow the provided annotation guidelines
* Maintain consistent labels and terminology
* Review annotations for accuracy before submission
